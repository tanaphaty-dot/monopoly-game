# อธิบายระบบ Event และแผงซ้าย

ฐานโค้ดคือ Monopoly_GameOLD แล้วใส่กติกา Event จาก step12
ปุ่ม เมนู และบันทึกการเล่นยังเป็นภาษาไทย เพราะไฟล์ OLD เป็นภาษาไทยอยู่แล้ว
ชื่อช่องพิเศษและการ์ดใช้ภาษาอังกฤษตาม `EventTile` ของ step12
ไม่ได้เอาไฟล์แปลไทยของ step12 (`UiText`, `TileNames`, `LogText`) มาใช้

เอกสารนี้เขียนให้กลุ่ม 4 คน ใช้เล่ากับอาจารย์ได้
ไม่ได้ยกหน้าจอสีใหม่มาทั้งก้อน ใช้หน้าตาเดิมของโปรเจกต์
แล้วย้ายแค่กติกา Event กับตำแหน่งแผง

## หน้าจอวางยังไง

```
ซ้าย: สถานะผู้เล่น          กลาง: กระดาน           ขวา: บันทึกการเล่น
ตำแหน่ง เงิน เมือง โบนัส                          ข้อความว่าเกิดอะไรขึ้น

ล่าง: ปุ่มทอย / จั่วการ์ด / จ่ายประกัน / จบเทิร์น / ซื้อหรือบุก / บันทึก / ออก
```

แผงซ้ายตอบคำถามที่อาจารย์มักถามตอนเดโมว่า "ตอนนี้ใครอยู่ช่องไหน"
จุดสีข้างชื่อคือสีเดียวกับวงกลมบนกระดาน

## เดินหนึ่งตา เกิดอะไรบ้าง

```
กดทอยลูกเต๋า
    |
    +-- ติดคุกอยู่? --> ทอยหนี หรือจ่ายประกัน  (เทิร์นนี้ยังไม่เดิน)
    |
    +-- เดินตามแต้ม
    |       ถ้าเดินทะลุช่อง 0 ได้เงิน 200
    |
    +-- ตกช่องอะไร
            |
            +-- เมืองว่าง --------> ซื้อ หรือไม่ซื้อ
            +-- เมืองคนอื่น ------> บุก หรือจ่ายค่าเช่า
            +-- เมืองตัวเอง ------> ไม่มีอะไร กดจบเทิร์น
            +-- ช่องพิเศษ --------> ได้ผลทันที
            +-- ช่อง Event -------> ต้องกดจั่วการ์ด
                                    ถ้าจั่วได้ "เดินฟรี" จะเดินต่อ 3 ช่อง
                                    แล้วกลับไปเช็กช่องใหม่ทันที
กดจบเทิร์น
```

โค้ดของลำดับนี้อยู่ใน `GameController`
เริ่มที่ `rollDice()` แล้วส่งต่อไป `resolveLanding()`

## กระดาน ช่องพิเศษอยู่ตรงไหน

เมือง 12 ช่องยังอยู่ที่เดิม

| ช่อง | ชื่อบนกระดาน | ชนิดในโค้ด | ผล |
| :--- | :--- | :--- | :--- |
| 0 | Start | `START` | เดินผ่านได้ +200 ไม่ใช่ช่องจั่ว |
| 5 | Camp | `CAMP` | ได้เงิน 100 และได้ธงเกราะค่าย |
| 11 | Watch | `WATCHTOWER` | ส่องเมืองคนอื่น ขึ้นในบันทึกด้านขวา |
| 14 | Jail | `WAR_JAIL` | เดินมาเองแค่แวะเยี่ยม ยังไม่ติดคุก |
| 17 | Train | `TRAINING_GROUND` | ได้ธงซ้อมโจมตี |
| 3, 7, 10, 16, 20, 22, 23 | Event | `CHANCE` | ต้องกดจั่วการ์ด |

ชื่อบนกระดานเป็นภาษาอังกฤษตาม step12 เช่น Start, Camp, Watch, Jail, Train
คำอธิบายใน `getDescription()` ก็เป็นอังกฤษ เช่น `CAMP · HEAL +100 AND DEFENSE +50 NEXT SIEGE`

ตัวเลขผลของค่ายและสนามซ้อมอยู่ที่ `EventTile` ที่เดียว
`EventCard` กับ `SiegeSystem` ไปดึงตัวเลขจากตรงนั้น
จะได้ไม่เขียน 50 ซ้ำคนละค่า

## การ์ด 8 ใบ

สร้างที่ `EventCard.createDeck()`

| ใบ | ชนิด | ผล |
| :--- | :--- | :--- |
| Treasure | `TREASURE` | +200 |
| Supply Drop | `SUPPLY_DROP` | +100 |
| Tax | `TAX_PENALTY` | -100 ถ้าจ่ายไม่ไหว เงินเหลือ 0 ล้มละลาย และเมืองหลุดทั้งหมด |
| Jail Trap | `JAIL` | ไปช่อง 14 และติดคุก |
| Armor | `BUFF_DEFENSE` | ธงเดียวกับค่ายพัก ใช้ครั้งเดียวตอนถูกบุก |
| Free Move | `FREE_MOVE` | เดินต่อ 3 ช่อง ถ้าผ่านจุดเริ่มได้ +200 แล้วเช็กช่องใหม่ |
| Siege Discount | `ATTACK_DISCOUNT` | บุกครั้งถัดไปถูกลง 50 |
| Combat Drill | `COMBAT_DRILL` | ธงเดียวกับสนามซ้อม บุกครั้งถัดไปถูกลง 50 |

การ์ดที่จั่วได้ถูกเก็บในมือผู้เล่น
แผงซ้ายเลยโชว์ว่า "การ์ด กี่ใบ"
เซฟเกมจำชนิดการ์ดไว้ด้วย โหลดกลับมาได้

## คุก ทำไมทอยแล้วยังไม่เดิน

ติดคุกมีทางเดียว คือจั่วการ์ดกับดักคุก
เดินมาที่ช่อง 14 เองไม่ติด

ตอนติดคุก ปุ่มทอยไม่ได้แปลว่าเดิน แปลว่าทอยหนี

- ได้ 5 หรือ 6 ออกจากคุก เทิร์นนี้ยังไม่เดิน
- ได้ 1 ถึง 4 อยู่ต่อ นับครั้งไว้ที่แผงซ้าย เช่น `ติดคุก 1/3`
- ครบ 3 ครั้งแล้วยังไม่ออก ระบบปล่อยเอง เทิร์นนั้นก็ยังไม่เดิน
- หรือกดจ่ายประกัน 100 ก่อนทอย เงินไม่พอแค่จ่ายไม่ได้ ไม่ล้มละลาย

ตาถัดไปค่อยเดินปกติ

## โบนัสไปทำงานตอนบุกยังไง

ของเดิมกลุ่มนี้ บุกเมืองคือ "มีเงินพอจ่ายค่าบุก = ยึดได้"
ยังไม่สุ่มเต๋าต่อสู้ จึงไม่ยกสูตรรบทั้งก้อนมา
โบนัส Event เลยไปเปลี่ยนราคาค่าบุกอย่างเดียว อธิบายอาจารย์ได้ตรงๆ

```
เกราะ = ค่าเช่าของเมือง + (50 x จำนวนเมืองที่ติดกัน)
ค่าบุก = เกราะ + เกราะค่าย - โบนัสซ้อม - ส่วนลดการ์ด
```

- เกราะค่ายมาจากช่อง 5 หรือการ์ดเกราะ ของฝ่ายรับ
- โบนัสซ้อมมาจากช่อง 17 หรือการ์ดซ้อม ของฝ่ายบุก
- ส่วนลดมาจากการ์ดส่วนลด ของฝ่ายบุก

เงินไม่พอจ่ายค่าบุก โบนัสยังไม่หาย เก็บไว้ตาหน้า
เงินพอและบุกจริง โบนัสถูกใช้ทันที ครั้งเดียว
บันทึกด้านขวาจะพิมพ์ว่าบวกอะไร ลบอะไร จ่ายจริงเท่าไร

หอคอยไม่ได้ให้เงิน มันพิมพ์รายชื่อเมืองของคนอื่น พร้อมค่าเช่าและเกราะ
ใช้ดูตอนจะตัดสินใจว่าตาหน้าจะบุกเมืองไหน

## แผงซ้ายแต่ละบรรทัดมาจากไหน

`PlayerStatusPanel.updateStatus()` วาดใหม่ทุกครั้งที่เกมเปลี่ยน

- บรรทัดบนสุด คือผู้เล่นตาปัจจุบัน และช่องที่ยืนอยู่
- จุดสี คือ `id` ของผู้เล่น เรียงแดง น้ำเงิน เขียว ส้ม เหมือนบนกระดาน
- ตำแหน่ง อ่าน `player.getCurrentTileId()` แล้วไปเปิดช่องนั้นใน `Board`
- เงิน อ่าน `player.getMoney()`
- เมือง นับช่องที่ `owner` เป็นผู้เล่นคนนี้
- สถานะ อ่านธง `isInJail`, `hasCampDefense`, `hasTrainingBoost`, `hasSiegeDiscount` และจำนวนการ์ด

กรอบล่างของแผงซ้ายท่องช่องพิเศษไว้ จะได้ไม่ต้องจำเลขช่องตอนพรีเซนต์

## ปุ่มล่างเปิดเมื่อไร

`ActionControlPanel.updateControlState()`

| ปุ่ม | เปิดเมื่อ |
| :--- | :--- |
| ทอยลูกเต๋า | เทิร์นนี้ยังไม่ทอย |
| จั่วการ์ด | ตกช่อง Event แล้ว ยังไม่จั่ว |
| จ่ายประกัน | ติดคุก และยังไม่ทอยในเทิร์นนี้ |
| ซื้อเมือง / บุกยึด | ตกเมืองว่าง หรือเมืองคนอื่น |
| ไม่ซื้อ / จ่ายค่าเช่า | คู่กับปุ่มด้านบน |
| จบเทิร์น | ทอยแล้ว และไม่มีงานค้าง |

ข้อความเหนือปุ่มบอกว่าตอนนี้ควรทำอะไร ไม่ต้องเดา

## เซฟเกมเก็บอะไรเพิ่ม

บรรทัดผู้เล่นเดิมมี เงิน กับ ช่อง กับ ติดคุกหรือไม่
ตอนนี้ต่อท้ายด้วย จำนวนครั้งที่ทอยหนีคุก, เกราะ, ซ้อม, ส่วนลด
การ์ดในมืออยู่คนละบรรทัด เช่น `Card:0,TREASURE`

ไฟล์เซฟเก่าที่ยังไม่มีช่องพวกนี้ โหลดได้ ค่าที่ขาดถือว่าไม่มีโบนัส

## ประโยคสั้นๆ ตอนพรีเซนต์

1. กระดานยัง 24 ช่อง เมือง 4 สีเหมือนเดิม เพิ่มช่องพิเศษ 5 ช่อง ที่เหลือเป็นช่องจั่วการ์ด
2. ตกช่องการ์ดแล้วผู้เล่นกดจั่วเอง มี 8 แบบ เงิน ภาษี คุก เดินฟรี และโบนัสบุก
3. โบนัสไม่ได้สุ่มเพิ่ม มันไปปรับราคาค่าบุกครั้งถัดไป ใช้แล้วหาย
4. คุกต้องทอย 5-6 หรือจ่าย 100 เทิร์นที่ออกยังไม่เดิน
5. แผงซ้ายโชว์ตำแหน่งจริงของผู้เล่นทุกคน พร้อมเงิน เมือง และสถานะที่ใช้ตอนบุก
